# Plan 08-01: Hour 0 Cleanup, Deep Link Fix & SOS Rate Limiting

## Objective

Complete the pre-demo cleanup (zip, Prisma scripts, pnpm swap, .gitignore, package name), fix the WebSocket deep-link bug, and make SOS rate limiting actually work — including the limiter extraction the reference doc omits.

Purpose: The reference doc's `@limiter.limit("10/minute")` on `sos.py` fails as written (`limiter` lives in `main.py` which imports `sos` first — circular import; and `trigger_sos` lacks the `request: Request` parameter slowapi requires).
