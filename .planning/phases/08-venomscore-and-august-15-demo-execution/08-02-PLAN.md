# Plan 08-02: VenomScore Backend Engine

## Objective

Implement the backend storage, pure clinical domain algorithms, and REST/WebSocket endpoints for VenomScore ptosis tracking and antivenom estimation, as detailed in [docs/AUGUST_15_EXECUTION_PLAN.md](file:///c:/Users/OM%20Prakash/Documents/Nagaraksha-/docs/AUGUST_15_EXECUTION_PLAN.md#hours-13--venomscore-backend-person-b).

## Tasks

### Task 1: Database Schema & Models
- In `backend/app/database.py`, add `PtosisReading` table to `SCHEMA`.
- In `backend/app/models.py`, add `PtosisReadingRequest` Pydantic model.

### Task 2: Domain Classification Logic
- In `backend/app/domain.py`, implement:
  - `classify_venom_type(ptosis_readings, wound_readings) -> str`
  - `compute_dry_bite_probability(ptosis_readings, wound_readings, minutes_since_bite) -> float`
  - `estimate_antivenom_vials(venom_type, severity_score) -> dict`
  - `compute_venom_score(ptosis_readings, wound_readings, minutes_since_bite) -> dict`

### Task 3: API Route & App Registration
- Create `backend/app/routes/venom_score.py` with:
  - `POST /venom-score/{incident_id}/reading` (stores reading, recomputes score, broadcasts `VENOM_SCORE_UPDATE`)
  - `GET /venom-score/{incident_id}/score`
  - `GET /venom-score/{incident_id}/readings`
- Register `venom_score.router` in `backend/app/main.py` with prefix `/api` and tag `venom-score`.

### Task 4: Unit & Integration Tests
- In `backend/tests/test_domain.py`, add `TestVenomScore` tests (neurotoxic, hemotoxic, dry bite, vial estimation).
- In `backend/tests/conftest.py`, ensure `seeded_incident` fixture is available.
- In `backend/tests/test_routes.py`, add `TestVenomScore` route tests (baseline, ptosis trigger, 404 handling).

## Verification
- Run `cd backend && python -m pytest tests/ -v`
