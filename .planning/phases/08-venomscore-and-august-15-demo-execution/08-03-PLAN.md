# Plan 08-03: VenomScore Frontend Face Tracking & Hospital Packet

## Objective

Build the on-device client-side vision pipeline using `@mediapipe/tasks-vision`, real-time ptosis calculation, trend chart, store integration, and incident page hospital packet, as defined in [docs/AUGUST_15_EXECUTION_PLAN.md](file:///c:/Users/OM%20Prakash/Documents/Nagaraksha-/docs/AUGUST_15_EXECUTION_PLAN.md#hours-15--venomscore-frontend-person-a).

## Tasks

### Task 1: Dependencies & API Layer
- Install `@mediapipe/tasks-vision` in `frontend/`.
- In `frontend/lib/nagraksha.ts`, add `PtosisReading`, `VenomScoreResult`, `SubmitPtosisResponse` interfaces and `submitPtosisReading`, `getVenomScore` client functions.

### Task 2: Store & State Management
- In `frontend/store/sos-store.ts`:
  - Add `ptosisReadings: PtosisReading[]` and `venomScore: VenomScoreResult | null`.
  - Add `addPtosisReading` and `setVenomScore` actions.
  - In `updateFromWsEvent`, handle `VENOM_SCORE_UPDATE` by updating `venomScore`.

### Task 3: Chart & Vision Components
- Create `frontend/components/venom-score-chart.tsx` using Recharts to visualize closure % with 40% (ptosis) and 70% (severe) threshold lines.
- Create `frontend/components/venom-score.tsx`:
  - Dynamically load MediaPipe Face Landmarker WASM/model.
  - Track landmarks RU: 159, RL: 145, LU: 386, LL: 374 on video frames.
  - Calibrate personal baseline on first frame; compute % change, asymmetry, and ptosis severity on subsequent 10s intervals.
  - Automatically submit reading to `/api/venom-score/{incidentId}/reading` and display alerts/vials.

### Task 4: Incident Page Integration & Mocking
- In `frontend/app/incidents/[id]/page.tsx`, mount `VenomScore` alongside `WoundTracker` in victim view, and add VenomScore pre-arrival assessment in hospital view.
- In `frontend/test/handlers.ts`, add MSW mock handlers for POST reading and GET score.

## Verification
- Run `cd frontend && npx vitest run`
- Run `cd frontend && pnpm run build`
- Run `cd frontend && pnpm run lint`
