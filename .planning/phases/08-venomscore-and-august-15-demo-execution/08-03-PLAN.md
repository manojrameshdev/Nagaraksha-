# Plan 08-03: VenomScore Frontend Face Tracking & Hospital Packet

## Objective

Build the on-device client-side vision pipeline using `@mediapipe/tasks-vision`, real-time ptosis calculation, trend chart, store integration, and a live role-gated hospital pre-arrival packet.

Purpose: Deliver phase success criterion #3 — the frontend runs MediaPipe Face Landmarker on-device, computes baseline and percentage closure, visualizes the trend, and displays live pre-arrival packets for the hospital role — while closing the review's file-inventory gaps (realtime.ts union, missing recharts, nonexistent hospital surface).
Output: Working webcam VenomScore tracker + hospital packet + full frontend test/build gates green.

## Hospital Surface Decision (Review HIGH #3 — target does not exist)

The incident page (`page.tsx`) has no role split or hospital view, and `components/nagraksha/workspaces.tsx:276-319` is static demo data ("No clinical decision is calculated", line 311). This plan **builds a live role-gated hospital surface on `/incidents/[id]`**: when the URL carries `?role=hospital`, the page renders a VenomScore pre-arrival packet fed by the store's `venomScore` (updated in real time via the `VENOM_SCORE_UPDATE` WebSocket event). The static `HospitalWorkspace` in `workspaces.tsx` intentionally remains the compliance/stock demo surface and is **not** wired to live data — a documented decision, not an omission. This matches the reference demo script's `?role=hospital` tab switch.

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-03-01 | Tampering | MediaPipe WASM/model from CDN | medium | mitigate | pin exact URLs (@mediapipe/tasks-vision@0.10.3 wasm + official storage.googleapis.com model asset) over HTTPS; runtime-loaded only, never bundled |
| T-08-03-02 | Information Disclosure | webcam frames in memory | medium | mitigate | frames never persisted or transmitted — numeric apertures only; tracks stopped on stop/unmount; cancelled flag prevents stale async writes |
