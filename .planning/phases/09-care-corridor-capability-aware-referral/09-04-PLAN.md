# Plan 09-04: Care Corridor Frontend UI & Closed-Loop Timeline Component

## Objective

Build the frontend UI components, Zustand store extensions, and typed API clients for the Care Corridor closed-loop referral timeline and receiving hospital console, as specified in [docs/CARE_CORRIDOR_PLAN.md](file:///c:/Users/OM%20Prakash/Documents/Nagaraksha-/docs/CARE_CORRIDOR_PLAN.md#9-care-corridor-ui-design-frontend).

## Tasks

### Task 1: TypeScript Interfaces & API Client (`frontend/lib/nagraksha.ts` & `realtime.ts`)
- In `nagraksha.ts`, declare `FacilityCapability`, `CapabilityGapEvaluation`, `Referral`, `CareCorridorTimeline` types.
- Add client helper functions: `evaluateReferral`, `createReferral`, `acceptReferral`, `declineReferral`, `startTransport`, `confirmArrival`, `getCorridorTimeline`.
- In `realtime.ts`, add referral event types to the socket event union.

### Task 2: Zustand Store Integration (`frontend/store/sos-store.ts`)
- Add `activeReferral: Referral | null` and `corridorTimeline: CareCorridorTimeline | null` to `SosState`.
- Add actions: `setReferral`, `updateReferralFromWs`, `setCorridorTimeline`.
- Handle incoming referral WebSocket events (`REFERRAL_CREATED`, `REFERRAL_ACCEPTED`, `TRANSPORT_STARTED`, `PATIENT_ARRIVED`).

### Task 3: Timeline & Modal Components (`frontend/components/`)
- Create `frontend/components/care-corridor-timeline.tsx`:
  - Renders the 8 vertical steps from SOS -> First Facility -> Clinical Observation -> Capability Gap -> Referral -> Hospital Acceptance -> Ambulance -> Arrival.
  - Highlights capability gap warnings (e.g. *Mechanical Ventilation Missing at PHC*).
  - Shows ETA and live telemetric updates.
- Create `frontend/components/referral-action-modal.tsx`:
  - Clinician referral initiator modal & receiving hospital one-tap accept/decline console.

### Task 4: Incident Page Integration & Tests (`frontend/app/incidents/[id]/page.tsx`)
- Mount `CareCorridorTimeline` on `/incidents/[id]` page for both victim and hospital roles.
- Add MSW handlers in `frontend/test/handlers.ts`.
- Create `frontend/components/__tests__/care-corridor-timeline.test.tsx` verifying stage transitions and real-time updates.

## Verification

- Run `cd frontend && npx vitest run`
- Run `cd frontend && pnpm run lint`
- Run `cd frontend && pnpm run build`
