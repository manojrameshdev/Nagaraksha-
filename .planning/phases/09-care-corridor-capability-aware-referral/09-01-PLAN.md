# Plan 09-01: Facility Capability Model & SQLite Schema Migration

## Objective

Extend the SQLite database schema and Pydantic models to store facility capability tiers (`PHC`, `CHC`, `SDH`, `DH`, `TERTIARY`), explicit capability tags (`ASV`, `VENTILATION`, `ICU`, `BLOOD_BANK`, `DIALYSIS`, `EMERGENCY_CARE`), and the `Referral` lifecycle entity, as specified in [docs/CARE_CORRIDOR_PLAN.md](file:///c:/Users/OM%20Prakash/Documents/Nagaraksha-/docs/CARE_CORRIDOR_PLAN.md#7-database-schema-extensions-backendappdatabasepy).

## Tasks

### Task 1: Extend SQLite Schema & Migrations (`backend/app/database.py`)
- In `SCHEMA`, add `facilityLevel TEXT DEFAULT 'PHC'`, `capabilities TEXT DEFAULT 'ASV,EMERGENCY_CARE'`, `ventilatorCount INTEGER DEFAULT 0`, `icuBedsAvailable INTEGER DEFAULT 0` to `Hospital` table definition.
- In `SCHEMA`, add `CREATE TABLE IF NOT EXISTS Referral (...)` with indices on `incidentId` and `(toHospitalId, status)`.
- In `migrate_db()`, add safe column checks and `ALTER TABLE Hospital ADD COLUMN ...` for the 4 new columns.

### Task 2: Pydantic Data Models (`backend/app/models.py`)
- Add `FacilityCapabilities` and `HospitalCapabilityUpdate` models.
- Add `ReferralCreateRequest`, `ReferralAcceptRequest`, `ReferralDeclineRequest`, and `ReferralResponse` models.

### Task 3: Test Fixture & Schema Verification (`backend/tests/`)
- Update `conftest.py` fixtures to support hospital capabilities and referral rows.
- Add unit test in `backend/tests/test_domain.py` verifying `migrate_db()` and table creation.

## Verification

- Run `cd backend && python -m pytest tests/test_domain.py -v`
