# Plan 09-02: Clinical Capability-Gap Evaluator & Recommendation Filter

## Objective

Implement the pure domain clinical decision rules for identifying facility capability gaps based on patient observation telemetry (VenomScore ptosis, swelling progression, systemic signs) and ranking destination facilities that satisfy the required capabilities, as defined in [docs/CARE_CORRIDOR_PLAN.md](file:///c:/Users/OM%20Prakash/Documents/Nagaraksha-/docs/CARE_CORRIDOR_PLAN.md#5-capability-model--clinical-decision-rules).

## Tasks

### Task 1: Capability Gap Decision Rules (`backend/app/domain.py`)
- Implement `evaluate_capability_gap(...)`:
  - Rule 1: Neurotoxic envenomation with Moderate/Severe ptosis (>40%) triggers required `VENTILATION` and `ICU` (NAPSE STG Sec 4.2).
  - Rule 2: Rapid proximal swelling or spontaneous bleeding triggers required `BLOOD_BANK` and `ICU` (WHO 2016 Sec 7.4).
  - Rule 3: Oliguria / anuria triggers required `DIALYSIS` and `ICU`.
  - Computes `missing_capabilities`, `referral_required` boolean, clinical reason string, urgency level, and guideline citation.

### Task 2: Capable Hospital Ranking (`backend/app/domain.py`)
- Extend `rank_hospitals` or implement `rank_capable_hospitals(origin, hospitals, required_capabilities)`:
  - Filters out facilities missing mandatory capabilities or penalizes them heavily.
  - Generates clear user-facing explanation: `WHY this facility was selected` and `What the referring facility lacked`.

### Task 3: Unit Tests (`backend/tests/test_domain.py`)
- Add `TestCapabilityGapEvaluation`:
  - Test PHC without ventilator evaluating severe ptosis -> `referral_required: True`, `missing: ["VENTILATION", "ICU"]`.
  - Test District Hospital with all capabilities -> `referral_required: False`.
  - Test hemotoxic coagulopathy requiring Blood Bank.
  - Test capable ranking ordering (Mandya DH ranks above closer PHC due to ventilation capability).
