# Plan 09-02: Clinical Capability-Gap Evaluator & Recommendation Filter

## Objective

Implement pure domain clinical decision rules for identifying facility capability gaps based on patient observation telemetry (VenomScore ptosis percentChange/severity, swelling progression, systemic signs) and ranking destination facilities using a **hard capability filter**, as defined in [docs/CARE_CORRIDOR_PLAN.md](file:///c:/Users/OM%20Prakash/Documents/Nagaraksha-/docs/CARE_CORRIDOR_PLAN.md#5-capability-model--clinical-decision-rules) and refined by [09-REVIEWS.md](file:///c:/Users/OM%20Prakash/Documents/Nagaraksha-/.planning/phases/09-care-corridor-capability-aware-referral/09-REVIEWS.md).

## Tasks

### Task 1: Capability Gap Decision Rules (`backend/app/domain.py`)
- Implement `evaluate_capability_gap(...)`:
  - Input telemetry normalization: accepts `venom_type`, `ptosis_severity` (string), `ptosis_percent_change` (float), `swelling_progression`, and `systemic_signs` list.
  - Rule 1 (Impending Respiratory Paralysis): Neurotoxic envenomation with `ptosis_percent_change >= 40.0` OR `ptosis_severity.upper() in ["MODERATE", "SEVERE"]` mandates `VENTILATION` and `ICU` (NAPSE STG Sec 4.2).
  - Rule 2 (Severe Coagulopathy): `swelling_progression == "RAPID_PROXIMAL"` OR `"BLEEDING"` in `systemic_signs` mandates `BLOOD_BANK` and `ICU` (WHO 2016 Sec 7.4).
  - Rule 3 (Renal Failure): `"OLIGURIA"` in `systemic_signs` mandates `DIALYSIS` and `ICU` (NAPSE Sec 5.1).
  - Normalizes required capabilities to a deterministic, sorted list.
  - Computes `missing_capabilities`, `referral_required` boolean, deterministic clinical reason list, urgency level (`CRITICAL_IMMEDIATE` if ventilation missing, else `HIGH_PRIORITY`), and guideline citation.

### Task 2: Capable Hospital Hard-Filter & Ranking (`backend/app/domain.py`)
- Implement `rank_capable_hospitals(origin: dict, hospitals: list[dict], required_capabilities: list[str]) -> list[dict]`:
  - Hard filter: Disqualifies any hospital where `capabilities` does NOT contain every item in `required_capabilities`, or where `stock.status == "OUT"`.
  - Disqualified hospitals have `eligible: False`, `missingCapabilities: [...]`, `recommended: False`, and are ranked at the bottom.
  - Eligible hospitals are ranked by existing 40/30/30 composite score (Distance / Freshness / Compliance).
  - Highest-scoring eligible hospital receives `recommended: True` and clear explanation text: `whyRecommended` and `referralRationale`.

### Task 3: Unit Tests (`backend/tests/test_domain.py`)
- Add `TestCapabilityGapEvaluation`:
  - Test PHC without ventilator evaluating 50% ptosis -> `referral_required: True`, `missing: ["ICU", "VENTILATION"]`.
  - Test District Hospital with all capabilities -> `referral_required: False`.
  - Test hemotoxic coagulopathy requiring Blood Bank.
  - Test `rank_capable_hospitals` hard filter: closer PHC (5 km away, no vent) is marked ineligible; farther DH (22 km away, with vent) is recommended.
  - Test out-of-stock ASV hospital disqualification.
