  <action>
    Create `.prettierrc` with the following exact content:
    ```json
    {
      "semi": true,
      "singleQuote": true,
      "tabWidth": 2,
      "trailingComma": "all",
      "printWidth": 100,
      "bracketSpacing": true,
      "arrowParens": "always",
      "endOfLine": "lf"
    }
    ```

    Create `.prettierignore` with these entries:
    ```
    node_modules
    .next
    out
    build
    next-env.d.ts
    .gitignore
    .env*
    *.log
    backend/db/*.db
    backend/db/*.db-journal
    .planning
    docs
    model
    ```

    Install Prettier as a dev dependency using npm:
    ```bash
    npm install --save-dev prettier
    ```

    Update root `package.json` to add these scripts in the "scripts" section (insert after "dev": line, before "lint"):
    ```json
    "format:write": "prettier --write \"**/*.{ts,tsx,js,jsx,json,css,md,mjs}\" --ignore-path .prettierignore",
    "format:check": "prettier --check \"**/*.{ts,tsx,js,jsx,json,css,md,mjs}\" --ignore-path .prettierignore",
    ```

    The full scripts section should become:
    ```json
    "scripts": {
      "dev:frontend": "cd frontend && next dev -p 3000 --webpack 2>&1 | tee ../dev.log",
      "dev:backend": "cd backend && python3 -m uvicorn app.main:app --host 127.0.0.1 --port 8000 2>&1 | tee ../backend.log",
      "dev": "bash scripts/dev.sh",
      "format:write": "prettier --write \"**/*.{ts,tsx,js,jsx,json,css,md,mjs}\" --ignore-path .prettierignore",
      "format:check": "prettier --check \"**/*.{ts,tsx,js,jsx,json,css,md,mjs}\" --ignore-path .prettierignore",
      "lint": "cd frontend && eslint .",
      "db:push": "cd frontend && prisma db push --accept-data-loss",
      "db:generate": "cd frontend && prisma generate",
      "backend:seed": "cd backend && PYTHONPATH=. python3 -c 'from app.seed import run; run()'"
    }
    ```

    Do NOT modify any other file structure or content.
  </action>
  <acceptance_criteria>
